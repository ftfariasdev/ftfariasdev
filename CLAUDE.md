# Working in this repository

This repo generates the GitHub profile README of `ftfariasdev`. Start with `docs/HOW-IT-WORKS.md`.

## Ground rules

- **Never edit `README.md` or `assets/*.svg` by hand.** They are generated: change `src/content.json`,
  `src/tokens.json` or a component, then run `npm run build`.
- **Talk to Felipe in Portuguese; everything on the page is US English.**
- **Nothing private on the page or in a commit:** no phone number, no WhatsApp, no corporate email.
  This repo's git identity is `Felipe Teixeira Farias <farias_felipe@outlook.com.br>`; keep it that way.
- **Nothing that signals job hunting** ("open to work", "hire me", "available for…"), and no
  Softwrench client, screen or product detail.
- **AngularJS is never written "Angular".**
- **Third-party README widgets stay out** (typing SVG, readme stats, streaks, trophies, snake,
  visitor counters, shields.io walls). Every effect here is generated by this repo. The Spotify
  widget is the one exception.
- **Ask before pushing, opening a pull request, or changing anything on github.com.**

## Before every commit

```bash
npm test && npm run build && npm run check
```

One piece per commit, Conventional Commits 1.0.0 in English with a scope, for example
`feat(hero): add sunrise pv-cell name reveal`. Commit the generated `assets/` and `README.md`
together with the change that produced them, or the build check fails on the pull request.

## Things that will bite you

- **opentype.js 2.0.0 writes `NaN` into `toPathData()`** for several B612 glyphs, and browsers stop
  drawing a path at the first `NaN`. `src/lib/text.mjs` serializes glyph commands itself; there is a
  test covering printable ASCII in every face. Do not go back to `toPathData()`.
- **svgo's default preset removes `role="img"`** and can inline the CSS that reduced motion depends
  on. The overrides in `src/lib/optimize.mjs` exist for that; `npm run check` catches regressions.
- **The static frame is the design.** Write base styles as the final state and let keyframes describe
  the arrival, so the GitHub mobile app and reduced motion show a finished piece.
- **Minimum text size is 18px in the viewBox.** Below that, text is unreadable when the README column
  shrinks to 380px. Essential information (name, role, stack, links) must also exist as text in the
  README, never only inside an image.
- **Ids inside an SVG share the page namespace** when the file is inlined (the preview script does
  this), so prefer data attributes for wrappers.
- **Playwright's `emulateMedia` does not reach SVGs loaded through `<img>`.** Inline the SVG to test
  reduced motion.

## Checking a change visually

```bash
npm run preview hero --times=0,2.5,5,12   # writes preview/*.png (dark, light, reduced, 380px)
```

Look at the screenshots: dark, light, reduced motion and 380px wide, before calling a piece done.
